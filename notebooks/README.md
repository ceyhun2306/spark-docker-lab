# Spark Docker Lab

Bu repository PySpark, MinIO (S3 obyekt saxlama) və Jupyter Notebook mühitini Docker Compose vasitəsilə işlətmək və dərsləri/tapşırıqları saxlamaq üçün yaradılmışdır.

## 🚀 Texnologiyalar
* **Apache Spark** (Master & Worker)
* **Jupyter Notebook** (Python analitika mühiti)
* **MinIO** (S3 uyğun Data Lake saxlama sahəsi)
* **Docker & Docker Compose**

## 📂 Qovluq Strukturu
* `notebooks/` - Bütün Jupyter notebook (`.ipynb`) faylları burada saxlanılır.
* `docker-compose.yml` - Konteynerlərin quraşdırılma və işlədilmə faylı.
* `spark-defaults.conf` - Spark tənzimləmələri.
